Tietokoneen tiedostot ovat järjestyksessä kuin mapit hyllyssä. <Term id="kansio">Kansio</Term> on mappi, ja sen sisällä voi olla <Term id="tiedosto">tiedostoja</Term> ja toisia kansioita.

<Term id="polku">Polku</Term> on kansion osoite. Se kertoo reitin kansiosta toiseen, kuten katuosoite:

<Os only="windows">

```
C:\Users\maija\Documents
```

Kenoviiva `\` erottaa kansiot toisistaan.

</Os>

<Os only="mac">

```
/Users/maija/Documents
```

Kauttaviiva `/` erottaa kansiot toisistaan.

</Os>

Oma <Term id="kotikansio">kotikansiosi</Term> on yllä kohdassa `maija`. Terminaalissa sitä merkitään lyhyesti aaltoviivalla `~`.

## Missä kansiossa olen?

Terminaali on aina jossakin kansiossa, ihan kuin olisit kävelemässä talossa huoneesta toiseen. Komennot koskevat sitä kansiota, jossa olet. Siksi on tärkeää tietää, missä olet.

| Komento | Mitä se tekee |
|---|---|
| `pwd` | kertoo, missä kansiossa olet |
| `ls` | listaa, mitä kansiossa on (Windowsilla myös `dir`) |
| `cd kansio` | siirtyy kansioon |
| `cd ..` | siirtyy yhden kansion ylöspäin |
| `mkdir nimi` | luo uuden kansion |

Kokeile näitä alla. Ensimmäisessä harjoituksessa liikut kansioiden välillä, toisessa luot oman kansion.
