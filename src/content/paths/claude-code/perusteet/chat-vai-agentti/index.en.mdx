You may already have tried AI in the browser: you type a question, and the AI answers. That’s a **chat**. Claude Code is an **<Term id="agentti">agent</Term>**, and the difference is big.

## A chat answers, an agent acts

| Question | Chat in the browser | Agent (Claude Code) |
|---|---|---|
| What does it do? | writes an answer | reads and creates files, runs commands |
| Code | you copy it to the right place yourself | it writes the code directly into your project |
| Errors | you report the error and copy the fix | it can run the site, notice the error and fix it |
| Where? | in the browser | in the terminal, in your folder |

In a chat, you’re the middleman who moves text back and forth. An agent does the work itself, and you steer and check.

<NuppuSays pose="osoittaa">An agent gets to work, but you stay at the controls. Always read what you approve.</NuppuSays>

## Who decides?

Because an agent does things on your computer, it asks for permission. Before Claude Code edits a file or runs a command, it shows what it’s about to do and waits for your answer. This is called a <Term id="lupa">permission prompt</Term>. Always read what you approve. We’ll come back to this in lesson 2.5.

Claude Code works in the folder where you start it. That’s why every project gets its own folder, and Claude is always started in the project’s folder.

<ReadMore title="Why do you need to be more careful with an agent?">

In a chat, a bad answer is just a bad answer. An agent, on the other hand, can change many files at once. That’s why it’s worth planning first (plan mode, lesson 2.3) and making save points often (Git, lesson 2.6). Then even bold experiments are safe.
