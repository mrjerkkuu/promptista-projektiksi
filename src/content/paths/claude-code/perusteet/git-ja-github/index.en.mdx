Remember games where you can save before a difficult part? If everything goes wrong, you go back to the save point and try again. <Term id="git">Git</Term> does the same for code.

<NuppuSays pose="tallentaa">Save point set! When you save often, you can experiment boldly, because you can always go back.</NuppuSays>

## Git: save points on your computer

Git keeps track of the files in your project folder. When something is finished or works well, you make a save point, a <Term id="commit">commit</Term>. Every commit comes with a short message, for example “Added a contact page”.

With commits you can:

- see what has changed and when
- go back to an earlier version if Claude or you mess something up
- experiment boldly, because nothing is lost.

## GitHub: your saves in the cloud

<Term id="github">GitHub</Term> is an online service where Git projects are stored. There, a project is called a <Term id="repo">repo</Term>. When you send your commits to GitHub with the <Term id="push">push</Term> command, they are safe even if your computer breaks.

From GitHub, you can also share the project with others or publish it as a website.
