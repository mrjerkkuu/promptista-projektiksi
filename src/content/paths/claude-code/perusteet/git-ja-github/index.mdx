## Git: tallennuspisteet koneellasi

Git seuraa projektikansiosi tiedostoja. Kun jokin on valmis tai toimii hyvin, teet tallennuspisteen eli <Term id="commit">commitin</Term>. Jokaiseen commitiin liitetään lyhyt viesti, esimerkiksi ”Lisätty yhteystietosivu”.

Commitien avulla voit:

- nähdä, mitä on muuttunut ja milloin
- palata aiempaan versioon, jos Claude tai sinä sotkette jotain
- kokeilla rohkeasti, koska mitään ei menetetä.

## GitHub: tallennukset pilvessä

<Term id="github">GitHub</Term> on verkkopalvelu, jossa Git-projekteja säilytetään. Projektia kutsutaan siellä <Term id="repo">repoksi</Term>. Kun lähetät commitit GitHubiin komennolla <Term id="push">push</Term>, ne ovat tallessa, vaikka tietokoneesi hajoaisi.

GitHubista projektin voi myös jakaa muille tai julkaista verkkosivuna.
