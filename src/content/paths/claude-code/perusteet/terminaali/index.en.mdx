The <Term id="terminaali">terminal</Term> is like texting with your computer. You write a message, a <Term id="komento">command</Term>, and press Enter. The computer does what you asked and replies with text.

Clicking with the mouse and using the terminal are two ways of using the same computer. The terminal feels strange at first, but it has two advantages: you can install programs with a single line, and Claude Code works right in the terminal.

<Os only="windows">

On Windows, the terminal program is <Term id="powershell">PowerShell</Term>. It looks like this:

```
PS C:\Users\alex>
```

</Os>

<Os only="mac">

On a Mac, the terminal program is called <Term id="paate">Terminal</Term>. It looks like this:

```
alex@MacBook ~ %
```

</Os>

The start of the line is the <Term id="kehote">prompt</Term>. It means: “I’m ready, type a command.” You don’t type the prompt yourself; you type the command after it.

<NuppuSays pose="koodaa">The terminal looks a bit intimidating at first, but it’s just text. You can’t break anything in the practice terminal, so go ahead and experiment!</NuppuSays>

## Three things worth knowing

- Spelling matters. `git --version` works, `git--version` doesn’t.
- It’s fine if you don’t understand the answer. Read it calmly; often the last line tells you what matters.
- The practice terminal below is completely safe: it doesn’t touch your real files.

<Terminal mission="ensimmaiset-komennot" />

<ReadMore title="Can you break something with the terminal?">

Ordinary commands, like the ones used in this guide, are safe. Dangerous commands, such as deleting files, usually require a separate instruction. That’s why it’s a good habit to read what a command does before you press Enter. Above every command in this guide, there’s an explanation of what it does.
