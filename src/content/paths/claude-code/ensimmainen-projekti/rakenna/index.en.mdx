## 1. Approve the plan

When Claude asks whether to start carrying out the plan, choose the option where changes are approved one at a time. That way you see every file before it’s saved. Claude creates the files, for example `index.html`, `style.css` and `CLAUDE.md`, and asks for permission for each one.

Meanwhile, watch in VS Code as the files appear in the folder.

<NuppuSays pose="rakentaa">Now we’re building! Take your time watching what Claude does. You can always ask it what it’s doing and why.</NuppuSays>

## 3. Polish it by talking

Now comes the most fun part. Look at the site and tell Claude what you want to change:

```
Make the heading bigger and add a small dog emoji below it.
```

```
When I open the site on my phone, the facts overlap. Fix it.
```

After the changes, refresh the browser by clicking the reload button next to the address bar (the curved arrow). (You can also press F5 on Windows, Cmd+R on a Mac.)

<Tip title="Small steps">

Ask for one change at a time and check the result before the next one. If something goes wrong, you can go back with the command `/rewind`. When the site looks good, move on to the next lesson and save your work.

</Tip>

<ReadMore title="What’s in the files?">

- `index.html` is the page’s structure and content: headings, text and images.
- `style.css` defines the look: colors, fonts and layout.
- `script.js` (if one was made) adds features, for example buttons.

You can ask Claude to explain: “Explain index.html line by line for a beginner.”

</ReadMore>
