Tämä on valinnainen lisätehtävä. Julkaiset sivusi <Term id="github-pages">GitHub Pagesilla</Term> omaan osoitteeseen, jonka voit lähettää kenelle tahansa. Palvelu on ilmainen julkisille repoille.

## 1. Ota GitHub Pages käyttöön

1. Avaa reposi GitHubissa (komento `gh browse`).
2. Valitse ylävalikosta **Settings** ja vasemmalta **Pages**.
3. Kohdassa **Build and deployment** valitse **Source**-valikosta **Deploy from a branch**.
4. Valitse haaraksi **main** ja kansioksi **/ (root)**. Paina **Save**.

Lähde: [GitHub Pagesin julkaisulähteen asetukset](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## 2. Odota hetki ja avaa sivu

Julkaisu kestää yleensä muutaman minuutin. Sivusi osoite on muotoa:

```
https://käyttäjänimesi.github.io/oma-sivu/
```

Osoite näkyy myös samalla Pages-asetussivulla, kun julkaisu on valmis.

## 3. Päivitä sivua

Jokainen `git push` päivittää julkaistun sivun automaattisesti muutaman minuutin kuluessa.

<Tip type="warning" title="Kaikki näkevät sivun">

GitHubin ohjeen mukaan Pages-sivut ovat julkisesti nähtävillä internetissä. Älä julkaise henkilötietoja, joita et halua kaikkien näkevän, kuten osoitettasi tai puhelinnumeroasi.

</Tip>

Jos sivu ei näy, katso [vianmääritys](#/vianmaaritys/pages-ei-nay).

<ReadMore title="Mitä seuraavaksi?">

Olet tehnyt koko kierroksen: suunnitellut, rakentanut, tallentanut ja julkaissut. Seuraavaksi voit esimerkiksi

- lisätä sivulle uuden osion tai pienen pelin
- tehdä kokonaan uuden projektin omaan kansioonsa
- pyytää Claudea opettamaan, miten jokin sivusi osa toimii.

Pidä kiinni samoista tavoista: suunnittele ensin, commit usein ja lue, mitä hyväksyt.

</ReadMore>
