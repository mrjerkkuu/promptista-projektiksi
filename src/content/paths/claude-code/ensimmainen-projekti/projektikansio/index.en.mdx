Now the real project begins! With Claude, you’ll make a <Term id="staattinen-sivu">static website</Term> of your own: just <Term id="html">HTML</Term>, <Term id="css">CSS</Term> and <Term id="javascript">JavaScript</Term> files that the browser opens as they are. First you need a folder.

## 1. Practice first

<Terminal mission="projektikansio-harjoitus" />

## 2. Do the same for real

Open your own terminal and run the commands one at a time. The first takes you to your home folder, the rest create the folders and move into them:

```
cd ~
mkdir projects
cd projects
mkdir my-site
cd my-site
```

Check with the command `pwd` that you’re in the `my-site` folder.

<Os only="windows">

<Tip title="Why not in the Documents folder?">

On Windows, the Documents folder is often synced to the cloud with OneDrive, which can interfere with Git. A `projects` folder made in your home folder is a safer place.

</Tip>

</Os>

## 3. Start Git tracking

<Command id="git-init" />

Git replies that it created an empty repo (“Initialized empty Git repository”). The folder now has a hidden `.git` folder where the save points are stored. You don’t need to touch it.

## 4. Open the folder in VS Code

<Command id="code-open-folder" />

The folder is still empty, but files will soon start to appear in it.

<ReadMore title="Why this structure?">

When all your projects are in the same `projects` folder, they’re easy to find. Every project is its own folder and its own Git repo. When Claude Code is started in the project’s folder, it works only on that project.

</ReadMore>
