A builder doesn’t start laying bricks before the drawings are ready. The same goes for code. In <Term id="plan-mode">plan mode</Term>, Claude investigates and proposes, but doesn’t change a single file yet. You read the plan and decide.

## How to get into plan mode

- **Shift+Tab:** in Claude Code, press Shift+Tab until it says plan mode at the bottom. The key cycles through the modes: normal mode → edits are accepted automatically → plan mode.
- **A single message:** start your message with `/plan`, and only that message is handled in planning mode.

<NuppuSays pose="miettii">Think first, then do. A plan is much easier to change than a finished site.</NuppuSays>

## A good way to work

1. **Describe the goal** in plan mode: what, why and within which limits.
2. **Read the plan.** Is everything included? Is there anything you don’t want?
3. **Ask for changes:** “Leave out the contact form” or “Make this simpler”.
4. **Approve** when the plan is good. Only then does Claude start building.

A moment spent planning saves a lot of fixing later. You also learn what parts the project is made of.

<Tip title="Note">

The mode “edits are accepted automatically” (accept edits) means Claude doesn’t ask permission for file changes. As a beginner, stay in normal mode so that you see every change.

</Tip>
