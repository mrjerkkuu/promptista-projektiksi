Uusi keskustelu ei näe aiempien keskustelujen sisältöä. Miten Claude sitten tietää, millainen projektisi on? Vastaus on <Term id="claude-md">CLAUDE.md</Term>.

CLAUDE.md on projektikansiossa oleva tekstitiedosto, jonka Claude Code lukee **jokaisen keskustelun alussa**. Se on kuin muistilappu jääkaapin ovessa: pysyvät ohjeet, joita ei tarvitse toistaa joka kerta.

<NuppuSays pose="lukee">Minäkin vilkaisen kauppalistaa aina, ennen kuin lähden kauppaan.</NuppuSays>

## Mitä sinne kirjoitetaan?

- Mikä projekti on ja kenelle se on tarkoitettu.
- Tekniset rajat, esimerkiksi ”vain HTML, CSS ja JavaScript, ei kirjastoja”.
- Toiveet tavoista: ”vastaa suomeksi”, ”selitä muutokset lyhyesti”.
- Asiat, joita ei saa tehdä: ”älä koskaan muuta kuvat-kansion tiedostoja”.

Esimerkki:

```markdown
# Oma sivu

Esittelysivu käsityöharrastuksestani. Lukijat ovat kavereitani.

## Säännöt
- Vain HTML, CSS ja JavaScript. Ei kirjastoja, ei build-vaihetta.
- Sivun pitää toimia hyvin puhelimella.
- Vastaa minulle suomeksi ja selitä muutokset lyhyesti.
```

Tiedosto kirjoitetaan <Term id="markdown">Markdown</Term>-muodossa, mutta tavallinen teksti toimii myös.

## Näin luot sen

- **Komennolla:** kirjoita Claude Codessa `/init`. Claude tutkii projektin ja tekee CLAUDE.md:n pohjan. Jos tiedosto on jo olemassa, Claude ehdottaa parannuksia.
- **Pyytämällä:** ”Lisää CLAUDE.md:hen sääntö, että sivun pitää toimia puhelimella.”
- **Itse:** avaa tiedosto VS Codessa ja muokkaa.

<ReadMore title="Muistaako Claude jotain itsekin?">

Kyllä. Claude voi kirjoittaa itselleen muistiinpanoja esimerkiksi korjauksistasi ja toiveistasi, ja se lukee ne seuraavissa keskusteluissa. Se päättää kuitenkin itse, mitä tallentaa. Kun haluat, että jokin ohje on varmasti voimassa, kirjoita se CLAUDE.md:hen.
