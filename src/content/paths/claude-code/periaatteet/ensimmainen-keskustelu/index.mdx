Nyt pääset juttelemaan Clauden kanssa. Tehdään se harjoituskansiossa, jotta kokeilut eivät sekoitu muihin tiedostoihisi.

## 1. Luo harjoituskansio ja käynnistä Claude

Avaa terminaali ja kirjoita nämä komennot yksi kerrallaan. Ensin luodaan kotikansioon kansio `harjoitus`, sitten siirrytään sinne:

```
mkdir harjoitus
cd harjoitus
```

Käynnistä sitten Claude Code:

<Command id="start-claude" />

Claude Code toimii aina siinä kansiossa, jossa käynnistät sen. Siksi ensin `cd`, sitten `claude`.

## 2. Puhu kuin ihmiselle

Kirjoita viesti ja paina Enter. Claude ymmärtää suomea hyvin. Kokeile esimerkiksi:

```
Moi! Kerro lyhyesti, mitä osaat tehdä tässä kansiossa.
```

```
Luo tiedosto tervehdys.txt, jossa lukee: Hei maailma!
```

Kun Claude haluaa luoda tiedoston, se kysyy lupaa. Lue, mitä se aikoo tehdä, ja hyväksy, jos se vastaa pyyntöäsi.

## 3. Hyödyllisiä näppäimiä ja komentoja

| Mitä | Miten |
|---|---|
| Keskeytä Clauden työ | Esc |
| Näytä ohje | `/help` |
| Lopeta Claude Code | `/exit` |

Kauttaviivalla alkavat komennot ovat Claude Coden omia komentoja, eivät viestejä Claudelle.

<ReadMore title="Mitä jos Claude ymmärtää väärin?">

Paina Esc, niin Claude pysähtyy, ja tehty työ säilyy. Kerro sitten tarkemmin, mitä tarkoitit: ”Ei noin, vaan…”. Keskustelu on yhteistyötä, ja tarkennukset ovat täysin normaaleja.

Lähde: [Claude Coden interaktiivinen tila](https://code.claude.com/docs/en/interactive-mode).
