Now you get to chat with Claude. Let’s do it in a practice folder so that your experiments don’t get mixed up with your other files.

## 1. Create a practice folder and start Claude

Open the terminal and type these commands one at a time. First you create a folder called `practice` in your home folder, then you move into it:

```
mkdir practice
cd practice
```

Then start Claude Code:

<Command id="start-claude" />

Claude Code always works in the folder where you start it. That’s why it’s `cd` first, then `claude`.

<NuppuSays pose="vilkuttaa">Say hi to Claude! You can write in plain language, just as if you were writing to a friend.</NuppuSays>

## 2. Talk to it like a person

Type a message and press Enter. Try, for example:

```
Hi! Tell me briefly what you can do in this folder.
```

```
Create a file greeting.txt that says: Hello world!
```

When Claude wants to create a file, it asks for permission. Read what it’s about to do, and approve if it matches your request.

## 3. Useful keys and commands

| What | How |
|---|---|
| Interrupt Claude’s work | Esc |
| Show help | `/help` |
| Quit Claude Code | `/exit` |

Commands that start with a slash are Claude Code’s own commands, not messages to Claude.

<ReadMore title="What if Claude misunderstands?">

Press Esc, and Claude stops; the work done so far is kept. Then explain more precisely what you meant: “Not like that, but…”. The conversation is teamwork, and clarifications are completely normal.

Source: [Claude Code’s interactive mode](https://code.claude.com/docs/en/interactive-mode).
