## Lopuksi: oletko kirjautunut?

Kirjautumiset eivät näy versiotarkistuksissa. Varmista vielä nämä:

- **GitHub CLI:** komento `gh auth status` kertoo, millä tilillä olet kirjautunut GitHubiin.
- **Claude Code:** kun käynnistät `claude`-komennon, se ei kysy kirjautumista vaan näyttää kehotteen.

Jos jokin kohta ei toimi, palaa kyseisen työkalun oppituntiin tai katso [vianmääritys](#/vianmaaritys). Mitään ei tarvitse asentaa kahdesti, jos versiotarkistus jo toimii.
