## Finally: are you signed in?

Signing in doesn’t show up in the version checks. Check these too:

- **GitHub CLI:** the command `gh auth status` tells you which account you’re signed in to GitHub with.
- **Claude Code:** when you start the `claude` command, it doesn’t ask you to sign in but shows the prompt.

If something doesn’t work, go back to that tool’s lesson or see [troubleshooting](#/vianmaaritys). You don’t need to install anything twice if the version check already works.
