## 3. Sign in

Start Claude Code by typing:

<Command id="start-claude" />

The first time, Claude Code guides you through signing in:

1. Choose the sign-in method that matches your plan (Claude plan or Console account).
2. The browser opens. Sign in with the same account you used for the plan, and approve.
3. Go back to the terminal. When you see the welcome text and the prompt, you’re in.

You can quit by typing `/exit` and pressing Enter. Next time, you won’t be asked to sign in.

<Tip title="Claude asks whether you trust the folder?">

Claude Code may ask whether you trust the folder you started it in. If it’s your own folder, you can answer yes. We’ll look at folders and permissions more closely in section 2.

</Tip>
