## 3. Kirjaudu GitHubiin

<Command id="gh-auth-login" />

gh kysyy muutaman kysymyksen. Valitse nuolinäppäimillä ja vahvista Enterillä:

1. **Where do you use GitHub?** → GitHub.com
2. **What is your preferred protocol?** → HTTPS
3. **Authenticate Git with your GitHub credentials?** → Yes
4. **How would you like to authenticate?** → Login with a web browser

gh näyttää kertakäyttöisen koodin (esim. `ABCD-1234`). Paina Enter, jolloin selain aukeaa. Kirjaudu GitHubiin, syötä koodi ja hyväksy. Kun terminaali kertoo ”Logged in as” ja käyttäjänimesi, olet valmis.
