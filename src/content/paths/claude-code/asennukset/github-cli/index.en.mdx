<Term id="gh">GitHub CLI</Term> is GitHub’s own terminal tool, and its command is `gh`. With it, you sign in to GitHub once, and after that you can create repos and send your work to GitHub directly from the terminal.

GitHub also offers a Mac installer package (.pkg) at [github.com/cli/cli/releases/latest](https://github.com/cli/cli/releases/latest). According to the official instructions, the package is currently unsigned, so macOS may warn you about it. That’s why Homebrew is the recommended way.

## 3. Sign in to GitHub

<Command id="gh-auth-login" />

gh asks a few questions. Choose with the arrow keys and confirm with Enter:

1. **Where do you use GitHub?** → GitHub.com
2. **What is your preferred protocol?** → HTTPS
3. **Authenticate Git with your GitHub credentials?** → Yes
4. **How would you like to authenticate?** → Login with a web browser

gh shows a one-time code (e.g. `ABCD-1234`). Press Enter, and the browser opens. Sign in to GitHub, enter the code and approve. When the terminal says “Logged in as” followed by your username, you’re done.
