<Term id="github">GitHubissa</Term> projektisi säilyvät pilvessä, ja sieltä voit myöhemmin julkaista sivusi. Tili on ilmainen.

## 1. Luo tili

1. Mene osoitteeseen [github.com/signup](https://github.com/signup).
2. Anna sähköpostiosoite, salasana ja käyttäjänimi. Valitse sähköpostiosoite, jota haluat käyttää jatkossakin.
3. Vahvista sähköpostiosoitteesi viestillä, jonka GitHub lähettää.

<Tip title="Valitse käyttäjänimi huolella">

Käyttäjänimi näkyy julkisesti, ja se tulee myös julkaistun sivusi osoitteeseen (esim. `maija-meikalainen.github.io`). Lyhyt ja selkeä nimi on paras.

</Tip>

<NuppuSays pose="suojaa">Kaksivaiheinen tunnistautuminen on kuin ovessa olisi toinen lukko. Käyttöönotto vie hetken, mutta suojaa tiliäsi pitkään.</NuppuSays>

## 2. Ota käyttöön kaksivaiheinen tunnistautuminen

<Term id="kaksivaiheinen-tunnistautuminen">Kaksivaiheinen tunnistautuminen</Term> tarkoittaa, että kirjautumiseen tarvitaan salasanan lisäksi puhelimesi. Vaikka joku saisi salasanasi selville, hän ei pääse tilillesi. GitHub suosittelee sitä vahvasti.

1. Asenna puhelimeen todennussovellus, esimerkiksi Microsoft Authenticator tai Google Authenticator.
2. Avaa GitHubissa oikean yläkulman profiilikuvasta **Settings** → **Password and authentication**.
3. Valitse kaksivaiheisen tunnistautumisen käyttöönotto ja sovellus (Authenticator app). Lue sovelluksella näytön QR-koodi ja kirjoita sovelluksen näyttämä koodi GitHubiin.
4. **Tallenna palautuskoodit** (recovery codes) turvalliseen paikkaan, esimerkiksi tulosta ne tai tallenna salasanojen hallintaohjelmaan. Niillä pääset tilillesi, jos puhelin katoaa.

Lähde: [GitHubin ohje kaksivaiheiseen tunnistautumiseen](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication).

<ReadMore title="Miksi tekstiviesti ei ole paras vaihtoehto?">

GitHub tukee myös tekstiviestikoodeja, mutta suosittelee ensisijaisesti todennussovellusta. Tekstiviestit voidaan pahimmassa tapauksessa kaapata esimerkiksi huijauksella, jossa puhelinnumerosi siirretään toiselle SIM-kortille.

</ReadMore>
