Claude Code ei ole ilmainen. Tarvitset Claude-tilin, johon Claude Code kuuluu.

## Mikä tilaus tarvitaan?

Anthropicin virallisen ohjeen mukaan Claude Code vaatii jonkin näistä:

- **Pro**- tai **Max**-tilauksen (henkilökohtaiset kuukausitilaukset)
- **Team**- tai **Enterprise**-tilauksen (organisaatioiden tilaukset)
- **Console**-tilin (käyttöön perustuva laskutus kehittäjille).

**Ilmainen Claude-tili ei riitä:** siihen ei kuulu Claude Codea.

Aloittelijalle henkilökohtainen kuukausitilaus on yleensä selkein vaihtoehto, koska hinta on kiinteä. Console-tilillä maksetaan käytön mukaan, jolloin kulut voivat vaihdella.

## Tee näin

1. Luo tili osoitteessa [claude.ai](https://claude.ai), jos sinulla ei vielä ole tiliä.
2. Valitse tilaus, johon Claude Code kuuluu.
3. Muista, millä sähköpostiosoitteella kirjauduit. Samaa tiliä käytetään, kun kirjaudut Claude Codeen seuraavassa vaiheessa.
