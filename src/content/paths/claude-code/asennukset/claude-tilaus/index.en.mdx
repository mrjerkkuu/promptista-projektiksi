Claude Code isn’t free. You need a Claude account that includes Claude Code.

## Which plan do you need?

According to Anthropic’s official documentation, Claude Code requires one of these:

- a **Pro** or **Max** plan (personal monthly plans)
- a **Team** or **Enterprise** plan (plans for organizations)
- a **Console** account (usage-based billing for developers).

**A free Claude account isn’t enough:** it doesn’t include Claude Code.

For a beginner, a personal monthly plan is usually the clearest option, because the price is fixed. With a Console account you pay for what you use, so the costs can vary.

## Prices and plan details

Plan prices and usage limits change, so they aren’t listed on this page. See the up-to-date information on Anthropic’s pages:

- [Claude plans and pricing (claude.com/pricing)](https://claude.com/pricing)
- [Using Claude Code with a Pro or Max plan (Claude support page)](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan)
- [Claude Code installation instructions and requirements](https://code.claude.com/docs/en/setup)

## Do this

1. Create an account at [claude.ai](https://claude.ai) if you don’t have one yet.
2. Choose a plan that includes Claude Code.
3. Remember which email address you signed in with. You’ll use the same account when you sign in to Claude Code in the next step.
