Nyt kirjaudutaan sisään ja avataan välilehti, jolla Claude Code toimii.

## 1. Kirjaudu

Kun käynnistät Clauden ensimmäisen kerran, se pyytää kirjautumaan. Kirjaudu samalla tilillä, jolla teit tilauksen.

Jos sovellus pyytää viimeistelemään kirjautumisen selaimessa, tee se ja käynnistä sovellus sen jälkeen uudelleen.

<NuppuSays pose="koodaa">Code-välilehdellä syntyy koko projektisi. Tutustu siihen rauhassa, sillä mitään ei tarvitse vielä valita.</NuppuSays>

## 2. Avaa Code-välilehti

Sovelluksen vasemmassa reunassa on sivupalkki, ja sen yläosassa ovat välilehdet **Chat** ja **Code**. Tällä polulla käytetään vain Code-välilehteä, joten napsauta **Code**. Jos välilehdissä näkyy pelkkiä kuvakkeita, vie hiiri kuvakkeen päälle, niin näet sen nimen. Coden kuvakkeessa on merkit `</>` <Screenshot id="i01-code" alt="Coden kuvake" inline />.

<Screenshot id="k06-valilehdet-kuvakkeina" alt="Sivupalkin yläreuna, jossa välilehdet näkyvät pelkkinä kuvakkeina. Oikeassa reunassa ovat Chat (puhekupla) ja korostettuna Code (kulmasulkeet ja kauttaviiva)." />

Code-välilehdellä on kirjoituskenttä, johon kerrot Claudelle, mitä haluat. Kentän alla on rivi valintoja:

- **ympäristö:** työskenteleekö Claude omalla koneellasi (Local) vai pilvessä
- **projektikansio:** kansio, jossa Claude työskentelee
- **tila:** kuinka vapaasti Claude saa tehdä muutoksia
- **malli:** mikä Clauden malli tekee työn. Oletusvalinta käy hyvin.

<Screenshot id="k07-code-valilehti" alt="Code-välilehden kirjoituskenttä, jossa lukee Describe a task or ask a question. Kentän alla valintarivin vasemmassa reunassa ovat ympäristö This computer, projektikansio (tässä harjoitus) ja tila Auto, oikeassa reunassa malli." />

Tässä vaiheessa riittää, että näet näkymän. Valinnat ja ensimmäinen tehtävä tulevat aihealueella 2.
