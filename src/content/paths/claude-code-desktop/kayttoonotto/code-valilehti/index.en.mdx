Now let’s sign in and open the tab where Claude Code works.

## 1. Sign in

When you start Claude for the first time, it asks you to sign in. Sign in with the same account you used for the plan.

If the app asks you to finish signing in in the browser, do that and then restart the app.

<NuppuSays pose="koodaa">Your whole project takes shape on the Code tab. Take your time getting to know it; you don’t need to choose anything yet.</NuppuSays>

## 2. Open the Code tab

On the left side of the app there’s a sidebar, and at the top of it are the tabs **Chat** and **Code**. This path only uses the Code tab, so click **Code**. If the tabs only show icons, hover the mouse over an icon to see its name. The Code icon has the characters `</>` <Screenshot id="i01-code" alt="Code icon" inline />.

<Screenshot id="k06-valilehdet-kuvakkeina" alt="The top of the sidebar with the tabs shown as icons only. On the right are Chat (a speech bubble) and the highlighted Code (angle brackets and a slash)." />

The Code tab has a text box where you tell Claude what you want. Below the box there’s a row of options:

- **environment:** whether Claude works on your own computer (Local) or in the cloud
- **project folder:** the folder where Claude works
- **mode:** how freely Claude may make changes
- **model:** which Claude model does the work. The default choice is fine.

<Screenshot id="k07-code-valilehti" alt="The Code tab’s text box, which says Describe a task or ask a question. In the row of options below it, on the left, are the environment This computer, the project folder (here harjoitus) and the mode Auto, and on the right the model." />

At this point, it’s enough that you can see the view. The options and the first task come in section 2.
