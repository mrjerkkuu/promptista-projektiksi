Claude Code ei ole ilmainen. Tarvitset Claude-tilin ja tilauksen, johon Claude Code kuuluu.

## Mikä tilaus tarvitaan?

Anthropicin virallisen ohjeen mukaan työpöytäsovelluksen Claude Code vaatii jonkin näistä:

- **Pro**- tai **Max**-tilauksen (henkilökohtaiset tilaukset)
- **Team**- tai **Enterprise**-tilauksen (organisaatioiden tilaukset).

**Ilmainen Claude-tili ei riitä.** Jos tililläsi ei ole sopivaa tilausta, sovellus pyytää Code-välilehdellä päivittämään tilauksen.

Aloittelijalle henkilökohtainen tilaus on yleensä selkein vaihtoehto, koska hinta on kiinteä.

Tilauksessa on käyttöraja. Jos se tulee täyteen, sovellus kertoo, milloin voit jatkaa. Pro-tilauksen raja riittää yleensä hyvin, jos et tee sillä töitä täyspäiväisesti.

## Hinnat ja tilauksen tiedot

Tilausten hinnat ja käyttörajat muuttuvat, joten niitä ei kerrota tällä sivulla. Katso ajantasaiset tiedot Anthropicin sivuilta:

- [Claude-tilaukset ja hinnat (claude.com/pricing)](https://claude.com/pricing)
- [Työpöytäsovelluksen Claude Coden aloitusohje](https://code.claude.com/docs/en/desktop-quickstart)

## Tee näin

1. Luo tili osoitteessa [claude.ai](https://claude.ai), jos sinulla ei vielä ole tiliä.
2. Valitse [hinnastosivulta](https://claude.com/pricing) tilaus, johon Claude Code kuuluu.
3. Muista, millä sähköpostiosoitteella kirjauduit. Samalla tilillä kirjaudut työpöytäsovellukseen.
