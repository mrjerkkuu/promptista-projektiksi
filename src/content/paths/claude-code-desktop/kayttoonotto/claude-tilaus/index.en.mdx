Claude Code isn’t free. You need a Claude account and a plan that includes Claude Code.

## Which plan do you need?

According to Anthropic’s official documentation, Claude Code in the desktop app requires one of these:

- a **Pro** or **Max** plan (personal plans)
- a **Team** or **Enterprise** plan (plans for organizations).

**A free Claude account isn’t enough.** If your account doesn’t have a suitable plan, the app asks you to upgrade on the Code tab.

For a beginner, a personal plan is usually the clearest option, because the price is fixed.

A plan has a usage limit. If you reach it, the app tells you when you can continue. The Pro plan’s limit is usually plenty if you’re not using it for full-time work.

## Prices and plan details

Plan prices and usage limits change, so they aren’t listed on this page. See the up-to-date information on Anthropic’s pages:

- [Claude plans and pricing (claude.com/pricing)](https://claude.com/pricing)
- [Getting started with Claude Code in the desktop app](https://code.claude.com/docs/en/desktop-quickstart)

## Do this

1. Create an account at [claude.ai](https://claude.ai) if you don’t have one yet.
2. On the [pricing page](https://claude.com/pricing), choose a plan that includes Claude Code.
3. Remember which email address you signed in with. You’ll sign in to the desktop app with the same account.
