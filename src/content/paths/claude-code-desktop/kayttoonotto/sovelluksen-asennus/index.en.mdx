The <Term id="claude-tyopoytasovellus">Claude desktop app</Term> is installed like any other app: you download the installation file and open it. Claude Code comes with the app, so there’s nothing else to install.

## 1. Check your computer

<Os only="windows">

The app requires Windows 10 or newer.

</Os>

<Os only="mac">

The app requires macOS 13 (Ventura) or newer. You can see your version in the Apple menu under About This Mac.

</Os>

<NuppuSays pose="rakentaa">This is the only installation on this path. Claude Code comes with the app, so you’ll get to the good stuff soon!</NuppuSays>

## 2. Download and install

1. Go to Claude’s official download page: [claude.com/download](https://claude.com/download).
2. Download the version for your operating system.
3. Open the downloaded file and follow the installation instructions.

<Os only="mac">

If you see a window with the Claude icon and the Applications folder, drag the icon into the Applications folder.

</Os>

Only download the app from the official address. There are also look-alike pages online that could give you something else entirely.

## 3. Start it

<Os only="windows">

Click the Start button on the taskbar, type `Claude` and choose the app from the search results.

</Os>

<Os only="mac">

Open Finder, choose **Applications** in the sidebar and double-click Claude. (You can also press Cmd+Space, type `Claude` and press Enter.)

</Os>

The app updates itself when it starts, so you don’t need to download new versions yourself.
