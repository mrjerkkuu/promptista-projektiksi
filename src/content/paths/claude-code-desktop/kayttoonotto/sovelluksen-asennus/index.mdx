<Term id="claude-tyopoytasovellus">Clauden työpöytäsovellus</Term> asennetaan kuten mikä tahansa sovellus: lataat asennustiedoston ja avaat sen. Claude Code tulee sovelluksen mukana, joten muuta ei tarvitse asentaa.

## 1. Tarkista koneesi

<Os only="windows">

Sovellus vaatii Windows 10:n tai uudemman.

</Os>

<Os only="mac">

Sovellus vaatii macOS 13:n (Ventura) tai uudemman. Näet versiosi omenavalikosta kohdasta Tietoja tästä Macista.

</Os>

<NuppuSays pose="rakentaa">Tämä on polun ainoa asennus. Claude Code tulee sovelluksen mukana, joten pääset pian asiaan!</NuppuSays>

## 2. Lataa ja asenna

1. Mene Clauden viralliselle lataussivulle: [claude.ai/download](https://claude.ai/download).
2. Lataa versio omalle käyttöjärjestelmällesi.
3. Avaa ladattu tiedosto ja seuraa asennusohjetta.

<Os only="mac">

Jos näet ikkunan, jossa on Clauden kuvake ja Ohjelmat-kansio, vedä kuvake Ohjelmat-kansioon.

</Os>

Lataa sovellus vain virallisesta osoitteesta. Netissä on myös samannäköisiä sivuja, joiden kautta voi saada jotain aivan muuta.

## 3. Käynnistä

<Os only="windows">

Napsauta tehtäväpalkin Käynnistä-painiketta, kirjoita `Claude` ja valitse sovellus hakutuloksista.

</Os>

<Os only="mac">

Avaa Finder, valitse sivupalkista **Ohjelmat** ja kaksoisnapsauta Claudea. (Voit myös painaa Cmd+välilyönti, kirjoittaa `Claude` ja painaa Enter.)

</Os>

Sovellus päivittää itsensä käynnistyessään, joten uusia versioita ei tarvitse ladata itse.
