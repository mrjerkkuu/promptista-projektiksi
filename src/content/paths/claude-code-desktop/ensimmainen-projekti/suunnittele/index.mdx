Ennen rakentamista suunnitellaan. Tässä vaiheessa päätät, mitä sivulle tulee, ja Claude tekee siitä suunnitelman.

## 1. Valitse Plan-tila

Valitse kirjoituskentän alta tilaksi **Plan**. (Voit myös avata tilavalikon painamalla Windowsilla Ctrl+Shift+M tai Macilla Cmd+Shift+M.) <Term id="plan-mode">Plan-tilassa</Term> Claude tutkii ja suunnittelee, mutta ei muuta tiedostoja.

## 2. Kerro, mitä haluat

Kirjoita prompti, joka kertoo mitä, miksi ja millä rajoilla. Esimerkki:

```
Haluan tehdä yksinkertaisen verkkosivun, joka esittelee koiraani Nappia.
Sivulla on otsikko, lyhyt esittely, kolme hauskaa faktaa ja kuvan paikka.
Lukijat ovat ystäviäni ja sukulaisiani, joten sävy saa olla lämmin ja leikkisä.

Rajat:
- Käytä vain HTML:ää, CSS:ää ja tarvittaessa JavaScriptiä.
- Ei kirjastoja, ei build-vaihetta, ei Node.js:ää.
- Sivun pitää toimia hyvin myös puhelimella.

Tee ensin suunnitelma. Jos jokin on epäselvää, kysy minulta.
```

## 3. Lue ja muokkaa suunnitelmaa

Claude kertoo, mitä tiedostoja se tekee ja mitä niihin tulee. Lue suunnitelma rauhassa. Pyydä muutoksia omin sanoin, esimerkiksi ”Lisää loppuun yhteystiedot” tai ”Värit saisivat olla vihreän sävyjä”.

Pyydä lopuksi lisäämään suunnitelmaan projektin muistilappu:

```
Lisää suunnitelmaan myös CLAUDE.md, johon kirjataan projektin tavoite ja yllä olevat rajat.
```

Kun suunnitelma on mieleisesi, siirry seuraavaan aiheeseen, jossa rakentaminen aloitetaan.
