Suunnitelma on valmis, joten rakennetaan!

## 1. Hyväksy suunnitelma

Napsauta suunnitelmakortin **Accept**-painiketta. Älä valitse korostettua **Accept and use auto mode** -painiketta, koska silloin Claude tekisi muutokset kysymättä. Pelkkä **Accept** vaihtaa tilaksi **Manual**, joten näet jokaisen tiedoston ennen kuin se tallennetaan. Claude alkaa toteuttaa suunnitelmaa heti.

Claude luo tiedostot, esimerkiksi `index.html`, `style.css` ja `CLAUDE.md`, ja kysyy jokaisen kohdalla lupaa. Lue muutokset ja hyväksy ne valitsemalla **Allow once**, kuten aiheessa 2.1. Jos muutoksia on paljon ja luotat suunnitelmaan, napsauta **Always allow**. Istunto siirtyy silloin Accept edits -tilaan, ja Claude tekee loput tiedostot kysymättä.

<NuppuSays pose="rakentaa">Nyt rakennetaan! Katso rauhassa, mitä Claude tekee. Voit aina kysyä siltä, mitä se on tekemässä ja miksi.</NuppuSays>

## 2. Katso sivua

Napsauta keskustelussa tiedoston `index.html` nimeä, niin sivu aukeaa Browser-paneeliin. Voit myös avata `oma-sivu`-kansion Resurssienhallinnassa tai Finderissa ja kaksoisnapsauttaa tiedostoa `index.html`, jolloin sivu aukeaa omaan selaimeesi.

Onneksi olkoon, teit juuri verkkosivun!

## 3. Viimeistele keskustelemalla

Nyt alkaa hauskin osa. Katso sivua ja kerro Claudelle, mitä haluat muuttaa:

```
Tee otsikosta isompi ja lisää sen alle koiraemoji.
```

```
Kun teen selainikkunasta kapean, faktat menevät päällekkäin. Korjaa se.
```

Jos katsot sivua omassa selaimessasi, päivitä se muutosten jälkeen napsauttamalla osoiterivin vieressä olevaa päivityspainiketta <Screenshot id="i06-paivitys" alt="kaareva nuoli" inline />.

<Tip title="Pienin askelin">

Pyydä yksi muutos kerrallaan ja tarkista tulos ennen seuraavaa. Jos jokin menee pieleen, pyydä Claudea perumaan muutos. Muutokset näet keskustelun luvuista (aihe 2.3).

</Tip>

<ReadMore title="Mitä tiedostot sisältävät?">

- `index.html` on sivun runko ja sisältö: otsikot, tekstit ja kuvat.
- `style.css` määrää ulkoasun: värit, fontit ja asettelun.
- `script.js` (jos sellainen tehtiin) lisää toimintoja, esimerkiksi painikkeita.

Voit pyytää Claudea selittämään: ”Selitä index.html rivi riviltä aloittelijalle.”

</ReadMore>
