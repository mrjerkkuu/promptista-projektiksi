## 1. Approve the plan

Click the plan card’s **Accept** button. Don’t choose the highlighted **Accept and use auto mode** button, because then Claude would make the changes without asking. Plain **Accept** switches the mode to **Manual**, so you see every file before it’s saved. Claude starts carrying out the plan right away.

Claude creates the files, for example `index.html`, `style.css` and `CLAUDE.md`, and asks for permission for each one. Read the changes and approve them by choosing **Allow once**, as in topic 2.1. If there are lots of changes and you trust the plan, click **Always allow**. The session then switches to Accept edits mode, and Claude makes the rest of the files without asking.

<NuppuSays pose="rakentaa">Now we’re building! Take your time watching what Claude does. You can always ask it what it’s doing and why.</NuppuSays>

## 2. Look at the site

Click the name of the file `index.html` in the conversation, and the page opens in the Browser panel. You can also open the `my-site` folder in File Explorer or Finder and double-click the file `index.html`, and the page opens in your own browser.

Congratulations, you just made a website!

## 3. Polish it by talking

Now comes the most fun part. Look at the site and tell Claude what you want to change:

```
Make the heading bigger and add a dog emoji below it.
```

```
When I make the browser window narrow, the facts overlap. Fix it.
```

If you’re looking at the site in your own browser, refresh it after changes by clicking the reload button next to the address bar <Screenshot id="i06-paivitys" alt="curved arrow" inline />.

<Tip title="Small steps">

Ask for one change at a time and check the result before the next one. If something goes wrong, ask Claude to undo the change. You can see the changes from the numbers in the conversation (topic 2.3).

</Tip>

<ReadMore title="What’s in the files?">

- `index.html` is the page’s structure and content: headings, text and images.
- `style.css` defines the look: colors, fonts and layout.
- `script.js` (if one was made) adds features, for example buttons.

You can ask Claude to explain: “Explain index.html line by line for a beginner.”

</ReadMore>
