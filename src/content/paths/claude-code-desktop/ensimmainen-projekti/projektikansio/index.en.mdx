Now the real project begins! With Claude, you’ll make a <Term id="staattinen-sivu">static website</Term> of your own: just <Term id="html">HTML</Term>, <Term id="css">CSS</Term> and <Term id="javascript">JavaScript</Term> files that the browser opens as they are.

## 1. Come up with a topic

Small and clear is best. Examples:

- a page about a hobby or a pet
- a recipe card for your favorite food
- a party invitation with a schedule and instructions for signing up
- a small memory game or quiz.

<NuppuSays pose="kansio">New project, new folder!</NuppuSays>

## 2. Make a project folder

In the `projects` folder, make a new folder called `my-site` the same way as in topic 0.3. Every project gets its own folder, so the practice folder’s files won’t get mixed up with this one.

## 3. Start a new session

1. Open Claude’s Code tab and click **+ New** in the sidebar.
2. Check that the environment is **This computer**.
3. Click the folder choice, choose **Open folder…** and find the `my-site` folder.

Don’t type a task yet. Next, you’ll plan what goes on the site.

<Tip title="Why a new session?">

A new session starts with a clean slate, and the practice conversation doesn’t take up space in the context. The session is also tied to a folder, so Claude now works in the `my-site` folder.

</Tip>
