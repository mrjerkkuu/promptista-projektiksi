## 1. Try it on a narrow screen

Many people open sites on their phone. Open the site in your own browser and make the browser window narrower by dragging its edge with the mouse. Does the text stay readable, and does everything fit? If not, tell Claude in your own words.

<Os only="windows">

If the window fills the whole screen, first click the middle button in the window’s top-right corner (Restore Down).

</Os>

<Os only="mac">

If the window fills the whole screen, leave full-screen mode with the green button in the window’s top-left corner.

</Os>

You can also ask Claude to check it: “Check how the site looks on a phone-sized screen, and tell me what you’d fix.”

## 2. Update the sticky note

When you’re happy with the site, ask:

```
Update CLAUDE.md so that it describes what's on the site now and what we agreed about the design.
```

That way the next session knows right away where things stand.

<NuppuSays pose="istuu">Good work deserves a coffee break! The project is waiting for you, and CLAUDE.md remembers where you left off.</NuppuSays>

## 3. Continue later

When you come back to the project another day, you have two ways to continue:

- **The same session:** click the session in the sidebar. The conversation continues where you left off.
- **A new session:** click **+ New** and choose `my-site` as the folder. Claude reads CLAUDE.md and knows the project’s basics.

A new session is often better when you start something new, because the context is then empty (topic 2.7).

## 4. Ask Claude to teach you

If you want to understand how your site works, ask:

```
Explain to a beginner how style.css sets the site's colors. Don't change anything.
```
