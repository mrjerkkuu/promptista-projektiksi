Claude can change many files at once. That’s why it’s important to see what it did before you continue.

## Look at the changes

When Claude has changed a file, the conversation shows the number of changed lines next to the file name, for example `+12 -1`: twelve lines added and one removed. Click the numbers, and the change view, the <Term id="diff">diff</Term>, opens. (If your project folder is a Git repo, the same numbers also appear in the **Changes** card next to the conversation.)

In the diff, you see file by file which lines were added and which were removed. You don’t need to understand every line of code. It’s enough to check whether the right file changed and whether the change looks sensible.

<NuppuSays pose="tutkii">I examine changes with a magnifying glass. If something looks odd, I ask Claude: “What does this change do?”</NuppuSays>

## Comment on lines

If a line needs to change, hover the mouse over the line in the diff and click the **+** sign that appears next to the line number. Type your feedback in the box and press Enter. The comment moves to the text box. When you’ve commented on all the lines you want, send the comments to Claude by pressing Enter in the text box. Claude makes the requested changes, and you see them as a new diff.

## If something goes wrong

- **Interrupt:** click the stop button. (You can also press Esc.)
- **Steer:** type a correction while it’s working and press Enter.
- **Undo:** ask Claude to undo the change, for example “Undo your last change to index.html”.

In Manual mode, you see every change before it’s made, and you can deny it.

<Tip title="Backup">

When the site is in good shape, make a copy of the project folder.

<Os only="windows">

Right-click the folder and choose **Copy**. Then right-click an empty spot and choose **Paste**. (You can also press Ctrl+C and Ctrl+V.)

</Os>

<Os only="mac">

Right-click the folder and choose **Duplicate**. (You can also press Cmd+D.)

</Os>

The copy’s name ends with the word copy. In the bonus task, you send your site to GitHub, which keeps every version you upload.

</Tip>
