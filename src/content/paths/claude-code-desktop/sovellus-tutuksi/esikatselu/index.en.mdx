When Claude makes a website, of course you want to see it. In the desktop app, you can do that in two ways.

## Inside the app

The Code tab has its own browser, the **Browser** panel. When an HTML file, for example `index.html`, is mentioned in the conversation, click the file name. The page opens in the panel next to the conversation.

You can also ask: “Show the page in the preview.” Claude often checks the page itself after making changes: it looks at how the page looks and fixes any errors it finds. If the panel doesn’t open, click **Browser** in the session’s title bar. (You can also press Ctrl+Shift+B on Windows or Cmd+Shift+B on a Mac.) If the conversation shows a card with an **Open** button, you can click that too.

## In your own browser

Open the project folder in File Explorer or Finder and double-click the file `index.html`. The page opens in your usual browser, such as Chrome, Edge or Safari. After changes, refresh the browser by clicking the reload button next to the address bar.

<NuppuSays pose="osoittaa">Try both ways and pick the one that feels most natural to you.</NuppuSays>

## Try it

Continue your practice session and type:

```
Make a page index.html that says Hello world in big letters and has a light blue background.
```

Approve the change and open the page in either way.

<ReadMore title="Claude asks permission to open a website">

You can also open other websites in the Browser panel. When Claude wants to act on a site for the first time, the app asks for permission: **Allow once**, **Always allow** (for this site) or **Deny**. Read the question as carefully as any other permission prompt. You won’t be asked for permission for your own page.
