Uusi istunto ei näe aiempien istuntojen keskusteluja. Miten Claude sitten tietää, millainen projektisi on? Vastaus on <Term id="claude-md">CLAUDE.md</Term>.

CLAUDE.md on projektikansiossa oleva tekstitiedosto, jonka Claude Code lukee **jokaisen istunnon alussa**. Se on kuin muistilappu jääkaapin ovessa: pysyvät ohjeet, joita ei tarvitse toistaa joka kerta.

<NuppuSays pose="lukee">Minäkin vilkaisen kauppalistaa aina, ennen kuin lähden kauppaan.</NuppuSays>

## Mitä sinne kirjoitetaan?

- Mikä projekti on ja kenelle se on tarkoitettu.
- Tekniset rajat, esimerkiksi ”vain HTML, CSS ja JavaScript, ei kirjastoja”.
- Toiveet tavoista: ”vastaa suomeksi”, ”selitä muutokset lyhyesti”.
- Asiat, joita ei saa tehdä: ”älä koskaan muuta kuvat-kansion tiedostoja”.

Esimerkki:

```markdown
# Oma sivu

Esittelysivu käsityöharrastuksestani. Lukijat ovat kavereitani.

## Säännöt
- Vain HTML, CSS ja JavaScript. Ei kirjastoja.
- Sivun pitää toimia hyvin puhelimella.
- Vastaa minulle suomeksi ja selitä muutokset lyhyesti.
```

Tiedosto kirjoitetaan <Term id="markdown">Markdown</Term>-muodossa, mutta tavallinen teksti toimii myös.

## Näin luot sen

- **Pyydä Claudea:** ”Tee projektille CLAUDE.md. Kerro siinä, että sivu on tehty vain HTML:llä, CSS:llä ja JavaScriptillä ja että vastaat minulle suomeksi.”
- **Lisää myöhemmin:** ”Lisää CLAUDE.md:hen sääntö, että sivun pitää toimia puhelimella.”
- **Muokkaa itse:** napsauta tiedoston nimeä keskustelussa, niin se aukeaa sovelluksen tiedostopaneeliin luettavana näkymänä. Napsauta paneelin oikeasta yläkulmasta **View source** (merkit `</>`), niin pääset muokkaamaan tekstiä. Aloita uusi sääntö omalla rivillään viivalla (`- `). Muutokset tallentuvat automaattisesti, ja silmäkuvake palauttaa luettavan näkymän.
