Claude does things on your computer, so safety is teamwork between you and Claude. Your most important tool is the **mode**, which you choose below the text box.

## Modes

| Mode | What Claude does | When |
|---|---|---|
| **Manual** | asks permission before every change and command | when you’re just getting started |
| **Accept edits** | edits files without asking, but asks before other commands | when you trust the changes and want to move faster |
| **Plan** | investigates and makes a plan without changing files | before a big change |
| **Auto** | acts without asking, but a check in the background blocks risky actions | when you’re already used to steering Claude |

If you don’t see Auto mode, no worries: you don’t need it on this path.

A permission prompt in Manual mode has three ways to approve: **Allow once** approves one change, **Always allow** switches the session to Accept edits mode and **Allow and switch to Auto** switches it to Auto mode. When you want to move to Accept edits mode, Always allow is the easiest way.

Start in Manual mode and move to Accept edits mode once you’re used to it. You can change the mode in the middle of a session. The app remembers your choice per folder, except for <Term id="plan-mode">Plan</Term> mode, which only applies to the current session.

<NuppuSays pose="suojaa">Not sure? Deny the change. Claude won’t mind; it will ask how you want to continue.</NuppuSays>

## Three safety rules

1. **Read what you approve.** If you don’t understand what Claude is about to do, deny the change and ask: “What does that do?” Be especially careful if something is about to be deleted or the change affects folders outside the project.
2. **Don’t give out passwords.** Don’t type passwords, bank credentials or personal ID numbers into the conversation. Claude doesn’t need them.
3. **Keys in a separate file.** If your project ever needs an <Term id="api-avain">API key</Term>, it’s saved in a <Term id="env-tiedosto">.env file</Term>, not in the code.

In the settings, you can turn on a mode where Claude asks permission for almost nothing. Anthropic recommends it only for separate, isolated environments. Don’t turn it on on your own computer.
