Nyt annat Claudelle ensimmäisen tehtävän. Jokainen keskustelu Code-välilehdellä on oma <Term id="istunto">istuntonsa</Term>: se työskentelee valitsemassasi kansiossa, ja sillä on oma keskusteluhistoria.

## 1. Tee harjoituskansio

Tee `projektit`-kansioon uusi kansio nimeltä `harjoitus` samalla tavalla kuin aiheessa 0.3. Tässä kansiossa saa kokeilla vapaasti.

## 2. Valitse asetukset

Avaa Code-välilehti. Jos näet aiemman istunnon, aloita uusi napsauttamalla sivupalkista <Screenshot id="i02-new" alt="+ New" inline />. Tee sitten valinnat kirjoituskentän alla olevalta riviltä:

1. **Ympäristö:** tarkista, että valittuna on **This computer** (valikon Local-ryhmässä). Se on yleensä valmiiksi valittuna. Claude työskentelee silloin omalla koneellasi.

   <Screenshot id="s02-ymparisto" alt="Ympäristövalikko auki. Local-ryhmän ainoa vaihtoehto This computer on valittuna, ja sen perässä on valintamerkki. Alempana ovat Cloud, WSL ja New environment." />

2. **Projektikansio:** napsauta kansion valintaa, valitse **Open folder…** ja etsi `harjoitus`-kansio.

   <Screenshot id="s03-open-folder" alt="Kansiovalikon alin vaihtoehto Open folder…" />

3. **Tila:** valitse **Manual**. (Valmiina voi olla <Screenshot id="i04-tila" alt="Auto" inline />.) Silloin Claude kysyy lupaa ennen jokaista muutosta. Tiloista kerrotaan lisää seuraavassa aiheessa.
4. **Malli:** valmiiksi valittu malli käy hyvin.

<NuppuSays pose="vilkuttaa">Ensimmäinen tehtävä! Pieni tehtävä on paras alku: näet heti, miten Claude toimii.</NuppuSays>

## 3. Anna tehtävä

Kirjoita kenttään esimerkiksi tämä ja paina Enter:

```
Tee tiedosto muistilista.txt, jossa on kolme vinkkiä hyvän kahvin keittämiseen.
```

Claude kertoo, mitä aikoo tehdä, ja näyttää muutoksen lupakyselyssä. Lue se. Hyväksy muutos valitsemalla **Allow once**. Jos painikkeessa lukee **Always allow**, avaa sen reunasta nuoli ja valitse Allow once. Se hyväksyy vain tämän muutoksen. Älä vielä napsauta itse **Always allow** -painiketta, koska silloin Claude ei enää kysy lupaa tiedostomuutoksiin tässä istunnossa. Jos et halua muutosta, napsauta **Deny**.

<Screenshot id="s05-lupakysely" alt="Lupakysely Allow Claude to edit muistilista.txt? Kortissa näkyy muutos: punaisella vanha rivi ja vihreällä uusi rivi. Alla ovat painikkeet Deny ja Always allow. Always allow -painikkeen oikeassa reunassa on nuoli, jonka takaa löytyy Allow once." />

Avaa sitten `harjoitus`-kansio Resurssienhallinnassa tai Finderissa: uusi tiedosto on siellä. Voit myös napsauttaa tiedoston nimeä keskustelussa, jolloin se aukeaa sovelluksen sisällä.

<Screenshot id="s10-tiedostolinkki" alt="Clauden vastauksessa tiedoston nimi muistilista.txt on sininen ja alleviivattu. Sitä napsauttamalla tiedosto on auennut keskustelun viereen paneeliin, jossa näkyvät sen rivit." />

<Tip title="Voit puuttua milloin tahansa">

Jos Claude lähtee väärään suuntaan, napsauta pysäytyspainiketta (neliö kirjoituskentän oikeassa reunassa). Voit myös kirjoittaa korjauksen kesken työn ja painaa Enter, jolloin Claude huomioi sen ennen seuraavaa vaihetta.

<Screenshot id="s06-pysaytys" alt="Kirjoituskenttä Clauden työskennellessä. Kentän oikeassa reunassa, mikrofonin vasemmalla puolella, on musta neliö eli pysäytyspainike." />

</Tip>
