Now you give Claude its first task. Every conversation on the Code tab is its own <Term id="istunto">session</Term>: it works in the folder you choose, and it has its own conversation history.

## 1. Make a practice folder

In the `projects` folder, make a new folder called `practice` the same way as in topic 0.3. You can experiment freely in this folder.

## 2. Choose the settings

Open the Code tab. If you see an earlier session, start a new one by clicking **+ New** in the sidebar. Then make your choices in the row below the text box:

1. **Environment:** check that **This computer** (in the menu’s Local group) is selected. It’s usually selected already. Claude then works on your own computer.
2. **Project folder:** click the folder choice, choose **Open folder…** and find the `practice` folder.
3. **Mode:** choose **Manual**. (Auto may be selected already.) Claude then asks permission before every change. There’s more about modes in the next topic.
4. **Model:** the model selected by default is fine.

<NuppuSays pose="vilkuttaa">Your first task! A small task is the best start: you’ll see right away how Claude works.</NuppuSays>

## 3. Give it a task

Type something like this into the box and press Enter:

```
Make a file notes.txt with three tips for brewing good coffee.
```

Claude tells you what it’s about to do and shows the change in a permission prompt. Read it. Approve the change by choosing **Allow once**. If the button says **Always allow**, open the arrow at its edge and choose Allow once. That approves only this change. Don’t click the **Always allow** button itself yet, because then Claude will stop asking permission for file changes in this session. If you don’t want the change, click **Deny**.

Then open the `practice` folder in File Explorer or Finder: the new file is there. You can also click the file name in the conversation, and it opens inside the app.

<Tip title="You can step in at any time">

If Claude heads in the wrong direction, click the stop button (the square at the right end of the text box). You can also type a correction while it’s working and press Enter, and Claude takes it into account before the next step.

</Tip>
