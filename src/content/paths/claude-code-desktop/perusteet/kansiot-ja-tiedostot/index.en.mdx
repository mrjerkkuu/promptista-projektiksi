The files on a computer are organized like binders on a shelf. A <Term id="kansio">folder</Term> is a binder, and inside it there can be <Term id="tiedosto">files</Term> and other folders. A website is a few files in the same folder, for example `index.html` and `style.css`.

## Claude works in the folder you choose

When you start working on the Code tab, you choose the folder Claude works in. It’s your project’s **project folder**. Claude reads and edits its files, and all new files go there too.

That’s why every project gets its own folder. It’s worth keeping your projects in one place, for example in a `projects` folder in your <Term id="kotikansio">home folder</Term>.

<NuppuSays pose="kansio">I keep my things in order: a folder of its own for every project. That way everything can be found, and Claude knows where it’s working too.</NuppuSays>

## Make a projects folder

<Os only="windows">

1. Click the Start button on the taskbar, type `File Explorer` and choose it from the search results. (You can also press the Windows key and the E key at the same time.)
2. On the left side of the window, choose **This PC**. Double-click **Local Disk (C:)**, then **Users** and finally the folder with your username. The name may be your first name or the beginning of your email address. Now you’re in your home folder. (You can also type `%USERPROFILE%` in the address bar at the top of the window and press Enter.)
3. Right-click an empty spot in the window and choose **New → Folder**. (You can also press Ctrl+Shift+N.)
4. Type `projects` as the folder name and press Enter.

</Os>

<Os only="mac">

1. Open Finder by clicking its icon (a blue smiling face) in the Dock, the row of icons at the bottom of the screen.
2. In the menu bar at the top of the screen, choose **Go → Home**. Now you’re in your home folder. (You can also press Cmd+Shift+H.)
3. In the menu bar, choose **File → New Folder**. (You can also press Cmd+Shift+N.)
4. Type `projects` as the folder name and press Enter.

</Os>

Use lowercase letters and hyphens instead of spaces in folder names, for example `my-site`. Names like that are sure to work everywhere.

<Os only="windows">

<Tip title="Why not in the Documents folder?">

On Windows, the Documents folder is often synced to the cloud with OneDrive, which can mess up the project’s files. A `projects` folder made in your home folder is a safer place.

</Tip>

</Os>

<Os only="mac">

<Tip title="Why not in the Documents folder?">

On a Mac, the Desktop and Documents folders may be synced with iCloud Drive, which can mess up the project’s files. A `projects` folder made in your home folder is a safer place.

</Tip>

</Os>

<ReadMore title="What is a path?">

A <Term id="polku">path</Term> is a folder’s address, like a street address. The path of your projects folder looks something like this:

<Os only="windows">

```
C:\Users\alex\projects
```

You see the path when you click File Explorer’s address bar.

</Os>

<Os only="mac">

```
/Users/alex/projects
```

Finder shows the path at the bottom of the window when you choose View → Show Path Bar from the menu.

</Os>

Claude sometimes uses a path to tell you where a file is. Then you know where to find it.

</ReadMore>
