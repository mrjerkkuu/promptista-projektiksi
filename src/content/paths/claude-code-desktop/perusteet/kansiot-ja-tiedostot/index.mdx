Tietokoneen tiedostot ovat järjestyksessä kuin mapit hyllyssä. <Term id="kansio">Kansio</Term> on mappi, ja sen sisällä voi olla <Term id="tiedosto">tiedostoja</Term> ja toisia kansioita. Verkkosivu on muutama tiedosto samassa kansiossa, esimerkiksi `index.html` ja `style.css`.

## Claude työskentelee valitsemassasi kansiossa

Kun aloitat työn Code-välilehdellä, valitset kansion, jossa Claude työskentelee. Se on projektisi **projektikansio**. Claude lukee ja muokkaa sen tiedostoja, ja sinne tulevat myös kaikki uudet tiedostot.

Siksi jokaiselle projektille tehdään oma kansio. Projektit kannattaa koota yhteen paikkaan, esimerkiksi `projektit`-kansioon <Term id="kotikansio">kotikansiossasi</Term>.

<NuppuSays pose="kansio">Minä pidän tavarani järjestyksessä: jokaiselle projektille oma kansio. Silloin kaikki löytyy, ja Claudekin tietää, missä se työskentelee.</NuppuSays>

## Tee projektit-kansio

<Os only="windows">

1. Napsauta tehtäväpalkin Käynnistä-painiketta, kirjoita `Resurssienhallinta` ja valitse se hakutuloksista. (Voit myös painaa Windows-näppäintä ja E-kirjainta yhtä aikaa.)
2. Valitse ikkunan vasemmasta reunasta **Tämä tietokone**. Kaksoisnapsauta **Paikallinen levy (C:)**, sitten **Käyttäjät** ja lopuksi kansiota, jolla on käyttäjänimesi (usein etunimesi). Nyt olet kotikansiossasi. (Voit myös kirjoittaa ikkunan yläosan osoiteriville `%USERPROFILE%` ja painaa Enter.)
3. Napsauta hiiren oikealla painikkeella ikkunan tyhjää kohtaa ja valitse **Uusi → Kansio**. (Voit myös painaa Ctrl+Shift+N.)
4. Kirjoita kansion nimeksi `projektit` ja paina Enter.

</Os>

<Os only="mac">

1. Avaa Finder napsauttamalla sen kuvaketta (sininen hymynaama) Dockissa eli näytön alareunan kuvakerivissä.
2. Valitse näytön yläreunan valikkoriviltä **Siirry → Koti**. Nyt olet kotikansiossasi. (Voit myös painaa Cmd+Shift+H.)
3. Valitse valikkoriviltä **Arkisto → Uusi kansio**. (Voit myös painaa Cmd+Shift+N.)
4. Kirjoita kansion nimeksi `projektit` ja paina Enter.

</Os>

Käytä kansioiden nimissä pieniä kirjaimia ja väliviivoja välilyöntien sijaan, esimerkiksi `oma-sivu`. Sellaiset nimet toimivat varmasti kaikkialla.

<Os only="windows">

<Tip title="Miksi ei Tiedostot-kansioon?">

Windowsissa Tiedostot-kansio (Documents) on usein OneDrive-pilvisynkronoinnin piirissä, mikä voi sotkea projektin tiedostoja. Kotikansioon tehty `projektit`-kansio on varmempi paikka.

</Tip>

</Os>

<ReadMore title="Mikä on polku?">

<Term id="polku">Polku</Term> on kansion osoite, kuten katuosoite. Projektit-kansiosi polku on esimerkiksi tällainen:

<Os only="windows">

```
C:\Users\maija\projektit
```

Näet polun, kun napsautat Resurssienhallinnan osoiteriviä.

</Os>

<Os only="mac">

```
/Users/maija/projektit
```

Finder näyttää polun ikkunan alareunassa, kun valitset valikosta Näytä → Näytä polkupalkki.

</Os>

Claude kertoo joskus polun avulla, missä tiedosto on. Silloin tiedät, mistä löydät sen.

</ReadMore>
