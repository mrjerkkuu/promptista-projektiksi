You may already have tried AI: you type a question, and the AI answers. That’s a **chat**. In the Claude desktop app, the chat and <Term id="claude-code">Claude Code</Term> are in the same app on different tabs, but they work in completely different ways. Claude Code is an **<Term id="agentti">agent</Term>**.

## A chat answers, an agent acts

| Question | Chat | Agent (Code tab) |
|---|---|---|
| What does it do? | writes an answer | reads and creates files, runs commands |
| Code | you copy it to the right place yourself | it writes the code directly into your project |
| Errors | you report the error and copy the fix | it can try the site, notice the error and fix it |
| Where? | in the conversation window | in the folder you choose on your computer |

In a chat, you’re the middleman who moves text back and forth. An agent does the work itself, and you steer and check.

<NuppuSays pose="osoittaa">Think of the agent as a helper you give the key to one room: your project folder.</NuppuSays>

## Who decides?

Because an agent does things on your computer, you decide how freely it may act. On the Code tab, you choose a mode. In one mode, Claude asks permission before every change; in another, it makes the changes itself and you review them afterwards. The modes are covered in section 2.

Claude Code works in the folder you choose for it. That’s why every project gets its own folder. You’ll learn how next.

<ReadMore title="Why do you need to be more careful with an agent?">

In a chat, a bad answer is just a bad answer. An agent, on the other hand, can change many files at once. That’s why it’s worth planning first and reviewing changes before you continue. You’ll practice both on this path.
