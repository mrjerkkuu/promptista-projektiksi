Olet ehkä jo kokeillut tekoälyä: kirjoitat kysymyksen, ja tekoäly vastaa. Se on **chat**. Clauden työpöytäsovelluksessa chat ja <Term id="claude-code">Claude Code</Term> ovat samassa sovelluksessa eri välilehdillä, mutta ne toimivat aivan eri tavalla. Claude Code on **<Term id="agentti">agentti</Term>**.

## Chat vastaa, agentti tekee

| Kysymys | Chat | Agentti (Code-välilehti) |
|---|---|---|
| Mitä se tekee? | kirjoittaa vastauksen | lukee ja luo tiedostoja, ajaa komentoja |
| Koodi | sinä kopioit sen itse oikeaan paikkaan | se kirjoittaa koodin suoraan projektiisi |
| Virheet | sinä kerrot virheen ja kopioit korjauksen | se voi kokeilla sivua, huomata virheen ja korjata sen |
| Missä? | keskusteluikkunassa | valitsemassasi kansiossa koneellasi |

Chatissa sinä olet välikäsi, joka siirtää tekstiä edestakaisin. Agentti tekee työn itse, ja sinä ohjaat ja tarkistat.

<NuppuSays pose="osoittaa">Agentti tarttuu toimeen, mutta sinä pysyt ohjaimissa. Valitsemasi tila ratkaisee, kuinka vapaasti se saa toimia.</NuppuSays>

## Kuka päättää?

Koska agentti tekee asioita koneellasi, sinä päätät, kuinka vapaasti se saa toimia. Code-välilehdellä valitset tilan. Yhdessä tilassa Claude kysyy lupaa ennen jokaista muutosta, toisessa se tekee muutokset itse ja sinä tarkistat ne jälkikäteen. Tilat käydään läpi aihealueella 2.

Claude Code työskentelee siinä kansiossa, jonka valitset sille. Siksi jokaiselle projektille tehdään oma kansio. Sen opettelet seuraavaksi.

<ReadMore title="Miksi agentin kanssa pitää olla tarkempi?">

Chatissa huono vastaus on vain huono vastaus. Agentti taas voi muuttaa monta tiedostoa kerralla. Siksi kannattaa suunnitella ensin ja tarkistaa muutokset ennen kuin jatkat. Molempia harjoitellaan tällä polulla.
