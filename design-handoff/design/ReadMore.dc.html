Lue lisää: mistä nimi Git tulee?
Nimellä ei ole virallista merkitystä. Gitin tekijä Linus Torvalds on kertonut nimenneensä sen leikillään itsensä mukaan.
Lue lisää: miksi Claude Code tarvitsee Gitiä?

Claude Code muokkaa tiedostojasi puolestasi. Git on turvaverkko: jos muutos ei miellytä, palaat edelliseen tallennuspisteeseen yhdellä komennolla. Siksi asennamme Gitin ennen Claude Codea.

Vertaus: Git on kuin ”kumoa”-painike, joka muistaa koko projektin historian – ei vain viimeistä muutosta.
