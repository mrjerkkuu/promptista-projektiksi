Asenna Git

Git antaa projektillesi tallennuspisteet. Asennus on yksi komento, ja lopuksi varmistetaan yhdessä, että kaikki toimii.

Mikä Git on?

TALLENNA
Tallennat hetken, jolloin projekti toimii.
KOKEILE

PALAA

Lue lisää: miksi Claude Code tarvitsee Gitiä?
Claude Code muokkaa tiedostojasi puolestasi. Git on turvaverkko: jos muutos ei miellytä, palaat edelliseen tallennuspisteeseen yhdellä komennolla.

Lämmittely: liiku kansioissa

Ennen oikeaa asennusta voit kokeilla komentoja harjoituspäätteessä. Se ei koske koneeseesi.

Vaihe 2 · Asennus

Asenna yhdellä komennolla

  1. Avaa PowerShell 7 Käynnistä-valikosta.
  2. Kopioi alla oleva komento ja liitä se PowerShelliin hiiren oikealla painikkeella.
  3. Paina Enter ja odota, kunnes näet tekstin ”Successfully installed”.
